GitHub anahtarı

Değişikliği siteye yazabilmek için bir kez GitHub token’ı gerekiyor (tarayıcında saklanır, sunucuya gitmez).
token nasıl alınır? (bir kerelik)
  1. github.com/settings/personal-access-tokens/new aç (Fine-grained token).
  2. Repository access → “Only select repositories” → veranda-araclari seç.
  3. Permissions → Repository permissions → Contents → Read and write.
  4. En altta Generate token → çıkan github_pat_… anahtarını kopyala, yukarı yapıştır, “anahtarı sakla” de.
Anahtar yalnız senin tarayıcında (localStorage) durur. Sayfanın adresi herkese açık ama anahtar olmadan kimse kaydedemez. Anahtarı kimseyle paylaşma; istemezsen “anahtarı sil” diyebilirsin.
